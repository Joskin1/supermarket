Supermarket Management System

A full-stack inventory and sales management platform built for a real Nigerian supermarket operation. The system gives the store owner complete visibility and control over products, stock, sales, and reporting — all from a single admin dashboard.

Tech Stack

Backend: Laravel 13, PHP 8.5

Admin Panel: Filament v5.5 (with custom pages, widgets, and resources)

Frontend: Livewire 4, Tailwind CSS 4

Database: MySQL 8.0

Auth: Laravel Fortify (login, email verification, password reset, 2FA support)

Permissions: Spatie Laravel Permission (Sudo / Admin roles)

Infrastructure: DDEV (local dev), Docker-ready

Core Features

Inventory Management

Full product catalog with categories, SKUs, barcodes, pricing, and stock tracking

Barcode scanning interface (Receive Stock page) that looks up products locally and via external APIs, with local caching

Stock entries and stock adjustments with full audit trails

Sales Pipeline

XLSX/CSV template-based daily sales import workflow — download a template, fill it in, upload it back

Batch processing with row-level success/failure tracking

Individual sales records with product snapshots for historical accuracy

Reporting & Analytics

Daily and weekly sales summaries (powered by pre-aggregated summary tables for performance)

Low-stock and out-of-stock alerts

Top-performing products and categories

Sales trends over time

Administration

Role-based access control (Sudo for the owner, Admin for staff)

Activity logging for audit compliance

System settings (business name, timezone, currency)

Database backup snapshots with download capability

Architecture Highlights

Clean separation: dedicated Actions, Services, Policies, and Enums layers

Filament resources use extracted Form, Table, and Schema classes for maintainability

Summary tables for reporting avoid expensive real-time aggregation queries

Comprehensive test suite (PHPUnit feature and unit tests)

Soft deletes across all core models for data safety
